# Learner Track — Module 7 预测表

**Story**: US7 | **Capabilities**: C-22…C-24

## 规则

1. `我的预测` 与 `依据` 两列 MUST 在运行**任何**验证命令之前填写并**提交**。
2. 提交之后才允许跑 `验证命令`，然后回填 `实测` 与 `一致?`。
3. 事后回填的预测**无效**，该行判未完成。
4. `依据` 写不出来就填"暂无依据" —— 那同样是有效信息。
   写"感觉是"或"应该吧"则等于没填。
5. #1–#6 的 `我的预测` MUST 写成**七类边界中的一层**
   （core / alloc / std / allocator / panic / runtime / OS services），
   再加一句你自己的机制理由。只写"缺库"或"不能用标准库"视为未填。

> `一致? = ✗` **不是失败**。它精确定位了一处心智模型缺口。
> 反过来，全中才值得怀疑 —— 检查一下是不是事后回填的。
>
> #1–#6 是 SC-006 的固定分母（= 6）。正确率 = 归属正确的条目数 / 6，通过线 = 100%。
> 不要按"某次构建实际报出了几条"改分母。
