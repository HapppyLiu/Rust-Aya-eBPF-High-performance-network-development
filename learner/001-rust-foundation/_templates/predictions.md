## 规则

1. `我的预测` 与 `依据` 两列 MUST 在运行**任何**验证命令之前填写并**提交**（§H2.2a）。
2. 提交之后才允许跑 `验证命令`，然后回填 `实测` 与 `一致?`。
3. 事后回填的预测**无效**，该行判未完成 —— 预测表的全部价值来自"先填后跑"这个顺序。
4. `依据` 不能写"感觉"或"应该是"。写不出依据说明还没形成判断，那就先填"暂无依据"，
   它同样是有效信息。

> `一致? = ✗` **不是失败**。它精确定位了一处心智模型缺口，是本 Feature 最有价值的产出。
> 反过来，未命中率为 0 才值得怀疑 —— 检查一下预测是不是事后回填的。
