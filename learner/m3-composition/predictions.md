# Learner Track — Module 3 预测表

**Story**: US3 | **Capabilities**: C-08…C-11

## 规则

1. `我的预测` 与 `依据` 两列 MUST 在运行**任何**验证命令之前填写并**提交**。
2. 提交之后才允许跑 `验证命令`，然后回填 `实测` 与 `一致?`。
3. 事后回填的预测**无效**，该行判未完成。
4. `依据` 写不出来就填"暂无依据" —— 那同样是有效信息，说明这一项你还没形成判断。
   写"感觉是"或"应该吧"则等于没填。

> `一致? = ✗` **不是失败**。它精确定位了一处心智模型缺口，是本模块最有价值的产出。
> 反过来，14 项全中才值得怀疑 —— 检查一下是不是事后回填的。
>
> **分配次数**（#4–#7、#12–#13）是本模块的核心预测项。先填次数，再让 `measure` 核对。
> 不要先跑再抄 —— 抄到的数字没有预测价值。
